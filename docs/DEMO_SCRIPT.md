# Demo Script

## Goal

Deliver a 2-minute demo that feels like a finished product launch, not a feature tour.

## 0:00 - Hook

"Every developer has a graveyard of abandoned projects. Museum of Dead Dreams turns that graveyard into an AI-powered museum, a revival engine, and a GitHub Copilot execution system."

## 0:15 - The problem

"GitHub is full of dead prototypes, forgotten hackathon builds, internal tools, and abandoned startup experiments. The cost is not only unused code. It is lost learning, lost product insight, and hidden technical capital."

## 0:30 - Enter a GitHub username

Show the welcome screen.

"Here, I enter a GitHub username. The app fetches public repositories, filters forks, ranks them by abandonment, and collects grounded repo evidence."

## 0:45 - Museum generated

Show the loading state, then the hall.

"Now the museum is generated dynamically. Each room represents one abandoned repo, complete with an epitaph, artifacts, cause of death, and Copilot commentary."

## 1:00 - Copilot Curator

Open an exhibit room and ask a question.

"This is the Copilot Curator. It answers grounded questions about the repo using recovered evidence like languages, commits, root files, README excerpts, and manifest snippets."

## 1:15 - Revival Plan

Open the Revival Plan.

"For each project, Copilot generates a full revival plan: diagnosis, architecture, modern stack, feature additions, go-to-market strategy, and a resurrection score."

## 1:35 - Resurrection Bay

Commit the project and open Resurrection Bay.

"If the project is worth saving, I can commit it into Resurrection Bay. That creates a persistent afterlife archive for the current museum."

## 1:50 - Copilot Kit

Show the Copilot kit.

"The key idea is that this does not stop at inspiration. The app generates a GitHub Copilot Resurrection Kit with repo instructions, a project skill, a revival plan, and an execution backlog that can be dropped into a real repo."

## 2:00 - Closing pitch

"Museum of Dead Dreams is built for GitHub Finish-Up-A-Thon because it is literally a product about finishing abandoned software. It turns dead repos into actionable revival plans, reusable Copilot kits, and second chances."
